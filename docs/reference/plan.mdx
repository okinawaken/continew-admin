我们深知一个优秀的项目不能闭门造车，它需要拥抱变化、海纳百川。正如项目的名字一样 ContiNew Admin（Continue New Admin），它将持续迭代优化，致力于提供开箱即用、持续舒适的开发体验。也许它现在不够完善，但请给它多一点时间。🍻

我们将慎重对待每一位关注者的星星之火💖：

- 对框架新增特性功能且比较简单，会在第一时间进行开发。
- 对框架新增特性功能但比较复杂，会延后几个版本制定相应的计划后进行开发。
- 与框架设计理念不太相符，或超出中后台管理框架范畴，将会视需求人数决定是否开发或建立独立分支。

<Callout type="info">
下方「历史任务」只记录**已完成**的事项，用于回看项目是怎么一步步长起来的。
</Callout>
